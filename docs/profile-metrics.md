# Profile metrics

This dashboard is inspired by the visual style of [lowlighter/metrics](https://github.com/lowlighter/metrics). Its SVG charts are generated by this repository's dependency-free Node.js script.

## What the cards mean

- **Public projects:** owned, non-fork public repositories, excluding this profile repository. The learning journal is included.
- **Contributions:** the sum of day counts in the publicly accessible GitHub calendar for the displayed range.
- **Active days:** calendar dates with at least one displayed contribution.
- **On GitHub since:** the account creation year.
- **Contribution rhythm:** those same contributions grouped by UTC calendar weekday, not hours worked.
- **Public code mix:** GitHub language-byte totals across owned public project repositories. This is not a measure of proficiency. Files counted depend on GitHub Linguist.
- **3D calendar:** each block is a real date. Green intensity follows GitHub's levels; height scales with the square root of that day's count.

Only public endpoints are collected. Private repository names, private source, credentials and application history are not queried or published. If the account owner enables anonymised private contributions on the public calendar, those aggregate counts may appear just as they do on the public profile.

## Refresh and failure behaviour

[Refresh profile metrics](../.github/workflows/profile-metrics.yml) runs daily at **01:17 UTC / 09:17 Asia/Singapore**, and can be started manually. GitHub schedules may run late.

It uses the repository's automatic, temporary GitHub token, with no new personal access token. The token's write permission is limited to this profile repository's contents. Refresh commits use github-actions[bot], so image updates are not presented as the owner's authored coding activity.

The collector validates complete dates and exact counts. If a source is unavailable or GitHub changes its calendar markup, the job fails before replacing the last good snapshot. The SVG footer shows its generation date.

Regenerate locally with Node.js 22+ and an authenticated GitHub CLI:

```bash
node scripts/generate-metrics.mjs
```
